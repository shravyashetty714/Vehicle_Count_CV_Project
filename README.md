# Vehicle Count Detection using OpenCV

This project implements a simple vehicle counting system using video processing and object detection with OpenCV in Python. It detects moving vehicles in a video and counts them as they cross a predefined virtual line.

## 🚗 Features

- Detects motion using frame differencing.
- Draws bounding boxes around moving vehicles.
- Counts vehicles crossing a specified horizontal line.
- Displays the vehicle count in real-time.

## 📂 Files

- `Detect_vehicle.py`: Main Python script for vehicle detection and counting.
- `Video1.mp4`: Input video file to be analyzed. (You must provide your own video.)
- `README.md`: Project overview and setup instructions.
